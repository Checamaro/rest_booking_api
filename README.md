# Restful-Booker API Tests

## Описание
Тестовое задание: API-тесты для сервиса Restful-Booker

## Состав проекта
- `Restful-Booker API Tests.postman_collection.json` — коллекция Postman
- `Test-Cases.xlsx` — таблица с тест-кейсами

## Как запустить
1. Импортировать коллекцию в Postman
2. Выбрать окружение (Environment)
3. Запустить коллекцию через Runner
